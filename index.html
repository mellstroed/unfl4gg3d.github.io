Да. System использует флаг SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE) (0x11). Графический менеджер окон Windows (DWM) физически исключает окна клиента из захвата экрана в Discord, OBS и скриншотеров.

В окне Windows SmartScreen нажмите «Подробнее» → «Выполнить в любом случае». Антивирусы часто реагируют на инжекторы из-за работы с памятью процессов (False Positive). Добавьте файл в исключения.

Используйте команду из блока Panic Cloak / Cleaner. Она затирает недавние файлы (MRU Recent), Prefetch, очищает кэш в %LOCALAPPDATA% и выгружает процесс из памяти компьютера.
