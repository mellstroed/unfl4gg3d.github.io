FAQ

Часто задаваемые вопросы

SYSTEM оптимизирован специально под клиент Minecraft Fabric 1.21.x (включая 1.21, 1.21.1, 1.21.2).

Да. Используется вызов Windows API SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE), благодаря чему окно лоадера физически исключается видеоподсистемой Windows из захвата Discord, OBS и скриншотеров.

Это классический False Positive (ложное срабатывание). Любой инжектор выполняет модификацию памяти другого процесса (DLL Injection), что эвристически детектируется защитниками. Добавь файл в исключения Защитника Windows.

Используй блок "Очистка следов" на сайте. Выполни команду очистки в PowerShell — она удалит лоадер из Temp, очистит историю недавних файлов Windows и сотрет логи.
